# Campaign 启动输入模板

## 最简用户指令

```text
根据我最新发布的帖子，分析它是什么活动、面向什么人群，制定搜索和互动计划。先只做 preview，不执行真实点赞、评论、回复或私信。
```

## 正式启动模板

```text
请为账号【账号名称】创建活动推广 Campaign。

内容来源：读取该账号最新发布的公开帖子。
如果最新帖子不是活动帖：【停止并告诉我 / 向前查找最近一条活动帖】。

请完成：
1. 识别活动类型、城市、时间、地点、价格、核心体验和报名方式。
2. 缺失或不确定的事实必须列出，不得猜测。
3. 生成人群画像、搜索主题、标签、关键词和排除条件。
4. 制定每日搜索、互动和复盘计划。

允许运行日期：【开始日期】至【结束日期】。
每日时间窗：【例如 10:00–12:00、15:00–18:00】。
每日总动作上限：【待填写】。
最小动作间隔：【待填写】分钟。
随机时间窗：【待填写】分钟。

允许动作：
- 点赞：【是/否】
- 评论帖子：【是/否】
- 回复评论：【是/否】
- 主动私信：【是/否】
- 回复用户私信：【是/否】

主动私信触发条件：【待填写】。
有效意向客户定义：【待填写】。
最终转化目标：【待填写】。

本次模式：preview。
在我明确确认单动作 smoke 前，不执行真实平台写入。
```

## 正式运行指令

正式运行不能只依赖一句“开始”。必须引用已确认的 Campaign、DailyPlan、动作预算和授权记录，并逐级通过：

```text
Campaign confirmed
→ preview passed
→ review passed
→ smoke-ready passed
→ user authorizes one action type
→ one-action smoke
→ verification passed
→ limited run authorization
```
