# XHS Operations Core 用户输入清单

本清单区分“现在必须提供”“开发中后期提供”和“不得在聊天或代码库提供”的信息。

## A. 现在必须提供

### A1. 首个运营任务

推荐先选一个边界明确的内容、活动或客服任务，并提供：

```text
活动名称：
活动类型：
活动日期与时间：
活动城市与地点：
活动价格：
名额或容量：
报名截止时间：
报名方式：
主办方：
活动内容与流程：
核心卖点：
适合人群：
不适合人群：
明确不能承诺或不能宣传的内容：
已经发布的小红书帖子链接（如有）：
```

如果资料尚未最终确定，请明确标注“待确认”，不要填写估计值。

### A2. 账号与身份

```text
账号属于个人、品牌还是机构：
账号显示名称：
由谁出镜或以谁的身份表达：
真实职业经历与可验证资质：
与本次业务相关的真实经验：
账号希望呈现的语气：
明确不能使用的人设或身份：
```

### A3. 转化目标

必须选一个 MVP 主目标：

- 用户回复或询问活动详情。
- 点击报名链接。
- 提交报名信息。
- 添加微信或其他客服渠道。
- 完成付款。

并说明什么算“有效线索”、什么算“完成转化”。

### A4. 互动与私信边界

请确认：

```text
是否允许点赞：
是否允许在相关帖子下发表评论：
是否允许回复他人评论：
是否只回复别人主动发来的私信：
是否允许主动私信已识别的相关用户：
如果允许主动私信，必须满足什么条件：
是否允许发送报名链接：
是否允许引导微信或客服：
每天可接受的动作上限：
```

### A5. 源帖子导入方式

默认方式：

- Agent 读取指定账号最近若干条公开帖子，排除置顶排序影响后选择真实发布时间最新的帖子。

请同时确认降级规则：

- 无法可靠判断时停止并请求用户提供链接。
- 最新帖子不是活动帖时停止。
- 最新帖子不是活动帖时继续向前寻找最近一条活动帖。

用户显式提供帖子链接作为稳定降级入口保留。

### A6. 目标使用者环境

```text
Windows 版本：
Codex Desktop 是否已经安装：
是否可安装 Python 和项目依赖：
常用浏览器：
是否有专门用于该账号的浏览器 profile：
最终使用者是否具备基础命令行操作能力：
```

## B. Phase 2–5 再提供

- 3–10 个历史或计划中的活动样本。
- 真实产品、服务、活动或内容资料。
- 价格、余位、报名方式等动态数据的维护负责人。
- 原创图片、活动照片和可公开素材。
- 获得授权的客户问题、咨询记录和活动反馈。
- 5–20 条你认为“像这个账号”的公开评论、回复或私信示例。
- 明确不喜欢的表达示例及原因。
- 品牌禁语、法律或合作方限制。

提供用户对话和客户案例前，需要脱敏并确认有权用于开发测试。

## C. 真实联调阶段再提供

- 一个可用于测试的小红书账号。
- 用户在本地完成账号登录。
- 用于首轮 smoke 的具体任务、目标内容和候选素材。
- 实际使用者参与安装和运行验收的时间。

## D. 不要在聊天或代码库中提供

- 小红书密码。
- Cookie、Token、验证码和浏览器登录态文件。
- 模型 API 密钥。
- 未经授权的客户手机号、微信号、身份证或付款资料。
- 不能公开的商业合同和完整客户名单。

这些内容如确实需要，应由使用者在本地受控配置或登录流程中输入，并确保被版本控制忽略。

## E. 当前最小回复模板

现阶段只需先回复以下内容：

```text
1. MVP 活动类型：
2. 一场真实活动的完整资料：
3. 已发布帖子链接（没有可写“暂无”）：
4. 账号身份与可验证资质：
5. MVP 主转化目标：
6. 什么算有效线索：
7. 是否允许主动私信，以及触发条件：
8. 是否允许发送报名链接或引导微信：
9. 源帖子采用手动链接还是自动监测：
10. 最终使用电脑的 Windows/Codex/Python 环境：
11. 每日运行时间窗、动作上限和复盘时间：
12. 最新帖子不是活动帖时的处理方式：
```
